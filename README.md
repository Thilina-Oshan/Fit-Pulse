# 🏋️ FitPulse - Modern Gym Management System

A high-performance, modern, and responsive Gym Management Web Application built with **React**, **TypeScript**, and **Tailwind CSS**.

---

## 🚀 Features Included

1. **Multi-Role Access Control:**
   - Admin Dashboard (Revenue analytics, Member tracking, KPIs)
   - Member Portal (Diet plans, Workout charts, Active Membership status)
   - Trainer View

2. **POS & Merchandise Store:**
   - Interactive shopping cart
   - Supplement & Equipment inventory management
   - Instant invoice generation

3. **Modern Dark UI:**
   - Crafted with Tailwind CSS and Lucide Icons for clean aesthetics.

---

## 🛠️ How to Run Locally

1. Extract the downloaded ZIP file.
2. Open terminal in the extracted folder:
   ```bash
   cd gym-management-system
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open your browser at `http://localhost:5173`
